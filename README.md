# NCAI --- Autonomous Intelligence. Driverless Innovation.

A responsive website for the NCAI autonomous-driving research team. The
site introduces the team and its technology, shares research-related
content, and provides contact and sponsorship inquiry forms.

## Features

-   **Home page** with a video hero, navigation, calls to action, and
    current-program statistics.
-   **Team page** featuring the director and research, software, and
    embedded/hardware team sections.
-   **Technology pages** for the overview and stack, publications, and
    insights.
-   **Media pages** for news and gallery content.
-   **Contact form** for collaboration, team, and general inquiries.
-   **Sponsorship form** for organizations interested in supporting
    hardware, compute, funding, internships, events, and software.
-   **Animated interactions** using Framer Motion.
-   **Responsive styling** using Tailwind CSS utility classes.
-   **Server-side form validation and email delivery** using Zod-style
    schema validation and Nodemailer.
